Sistema de Gestión de Citas - EPS Vida Sana
Sistema integral y modular para la administración, registro, agendamiento y control de citas médicas multidisciplinares para usuarios de la EPS Vida Sana.

🌐 Enlaces del Proyecto
Repositorio en GitHub: https://github.com/naimpacheco30/Proyecto-hospital-eps
Despliegue en Producción (Netlify): https://hospital-eps.netlify.app/

📋 Funcionalidades Principales
Autenticación y Registro Seguro de Usuarios: Control de acceso y creación de cuentas con validación numérica para documentos y contraseñas.
Agendamiento Multidisciplinar: Programación de citas para 5 especialidades médicas (Médico general, Psicología, Odontología, Toma de muestras y Especialistas).
Manejo Dinámico de Formularios: Adaptación de campos según el tipo de atención (selección de tipo de sesión para psicología, detalles de muestras o procedimientos odontológicos).
Validaciones de Seguridad: Prevención de citas en horarios o fechas pasadas y bloqueo de citas duplicadas en el mismo rango horario.
Gestión Integral de Agenda: Módulos interactivos para consultar el historial de citas activas, reprogramar fechas/horas y cancelar citas agendadas.
Persistencia de Datos: Almacenamiento estructurado en JSON para entorno de escritorio y almacenamiento local para la plataforma web. git clone https://github.com/naimpacheco30/Proyecto-hospital-eps.git
