# ADR-001: Diseño de almacenamiento para EPS Vida Sana

* **Estado:** Aceptado
* **Fecha:** 20 de octubre de 2026
* **Proyecto:** EPS Vida Sana
* **Decisión:** Utilizar Amazon S3 para el sitio web estático y para el almacenamiento privado de documentos.

## 1. Contexto

EPS Vida Sana necesita publicar su sitio web y organizar documentos relacionados con las funciones de registro de usuarios y gestión de citas médicas. Se requiere separar los archivos públicos de los privados, permitir la recuperación de versiones anteriores y controlar los costos de almacenamiento.

## 2. Decisión

Se utilizarán dos buckets de Amazon S3:

* **Bucket público:** `cuc-bp-eq34-dominguez-sitio-2026`, destinado a los archivos del sitio web estático.
* **Bucket privado:** `cuc-bp-eq34-dominguez-privado-2026`, destinado a documentos y archivos internos del proyecto.

El bucket privado organiza los objetos mediante los prefijos `usuarios/`, `citas/`, `documentos/`, `reportes/` y `respaldos/`.

Se habilita el versionado para conservar versiones anteriores y facilitar la recuperación de archivos.

## 3. Regla de ciclo de vida

Se creó la regla `retencion-sitio` en el bucket del sitio web con la siguiente configuración:

* Transición de versiones no vigentes a S3 Standard-IA después de 30 días.
* Transición de versiones no vigentes a S3 Glacier Flexible Retrieval después de 90 días.
* Eliminación permanente de versiones no vigentes después de 180 días.

Las acciones se aplican a versiones no vigentes. La configuración debe revisarse periódicamente para comprobar que cumple los requisitos de conservación y recuperación del proyecto.

## 4. Alternativas consideradas

* Mantener todos los objetos en S3 Standard.
* Utilizar clases de almacenamiento de menor costo para versiones antiguas.
* Eliminar versiones anteriores sin un periodo de retención.

Se eligió mantener las versiones vigentes disponibles y aplicar transiciones y eliminación únicamente a las versiones no vigentes.

## 5. Estimación de costos

Los cálculos se realizaron con AWS Pricing Calculator para la región US East (N. Virginia), utilizando supuestos ilustrativos de almacenamiento y solicitudes.

| Escenario                   |                    Costo estimado a 12 meses |
| --------------------------- | -------------------------------------------: |
| S3 Standard                 |                                     US$ 2,76 |
| Escenario con ciclo de vida |                                     US$ 3,48 |
| Diferencia                  | US$ 0,72 adicionales en el segundo escenario |

Con estos supuestos, el escenario con ciclo de vida no presenta ahorro. La diferencia puede estar relacionada con el volumen reducido y los cargos asociados a las clases de almacenamiento y las transiciones. Los valores no constituyen una factura real ni una medición del consumo efectivo del bucket.

## 6. Consecuencias

**Ventajas**

* Separación de los archivos públicos y privados.
* Recuperación de versiones anteriores.
* Organización lógica de los documentos.
* Posibilidad de controlar la retención de versiones antiguas.

**Riesgos y consideraciones**

* Las versiones archivadas pueden requerir restauración antes de ser consultadas.
* Las transiciones y solicitudes pueden generar cargos.
* La eliminación permanente impide recuperar las versiones eliminadas.
* Deben verificarse los permisos y la protección de los datos antes de almacenar información real de pacientes.

## 8. Conclusión

Amazon S3 permite separar el contenido público de los documentos privados de EPS Vida Sana. El versionado facilita la recuperación de cambios accidentales y la regla de ciclo de vida permite administrar versiones antiguas. Los costos deben revisarse con datos reales antes de adoptar la configuración como política definitiva.
